## 🇬🇧 OMG Premium TV 8.5.1

### 📺 Cleaner channels
- **No more mixed-up channels**: some playlists and Xtream panels reuse one id for different channels, so every Sky channel ended up inside Sky Cinema Uno. Now only versions of the same channel are merged, and every other channel goes back to its own place with its own TV guide.
- **One channel, every quality**: SD, HD, FHD and 4K of the same channel become a single channel. Inside you'll find a stream for each version ("Video Nina SD", "HD", "FHD", "4K"). This also works with playlists that have no `tvg-id` or a different id per quality.
- **Names without quality tags**: the channel list no longer shows HD, FHD, SD, 4K or HEVC ("La 7 HD" → "La 7"). The tags stay on the streams so you can pick the quality. "Rai 4K" stays "Rai 4K".
- Channels already saved in favourites or "continue watching" are still found.

### ▶️ Streams
- Verified streams 🌐 come first, followed by those the quick check couldn't confirm, now labelled **"not verified"**. They always go through the proxy.
- With several configurations installed, the ones that don't have a channel no longer show an error.

### 🧭 Texts and look
- Addon description in the configuration's language (Italian, English, Spanish, French).
- Texts that fit every app (Stremio, Nuvio…) and every source (M3U and Xtream). The service channel is now called **"Reload playlist"**.
- Channel placeholders keep "+" and accented letters ("Rai 1 +1").

### ⬆️ How to update
1. Update the addon: `docker compose pull && docker compose up -d`.
2. In each configuration open **⚙️ → Reload playlist**, or wait for the automatic refresh.
3. Restart Nuvio or Stremio. To see the new description, reinstall the addon with the same URL.
